# TC-002: Lives timer behavior when device time is changed manually

| Field | Value |
|-------|-------|
| Test Case ID | TC-002 |
| Requirement | [BUG-002](../bug-reports/BUG-002.md) |
| Module | Lives System |
| Test Name | Verify lives timer continues correctly after manual device time change |
| Priority | Medium |
| Test Environment | iPhone 15 Pro, iOS 17.4, Homescapes v6.x (latest App Store build) |
| Tester | Kseniia Romanovskaia |
| Test Date | - |
| Status | Not Tested |

## Preconditions
- Homescapes is installed and launched
- Player has fewer than 5 lives (fail a level to lose one if needed)
- Lives timer is actively counting down
- Access to device Settings is available

## Test Steps

| Step | Action | Expected Result | Actual Result | Status |
|------|--------|----------------|---------------|--------|
| 1 | Open Homescapes and confirm lives are below maximum | Lives counter shows less than 5, timer is visible and counting down | - | - |
| 2 | Note the current timer value (e.g. 18:45 remaining) | Timer value is recorded | - | - |
| 3 | Minimize Homescapes and open device Settings | Device Settings opens | - | - |
| 4 | Navigate to General > Date and Time, disable Set Automatically, advance time by 30 minutes | System time is manually changed | - | - |
| 5 | Return to Homescapes | App resumes | - | - |
| 6 | Observe the lives count and timer | Lives count should reflect 30 minutes of elapsed time, timer should continue counting down correctly | - | - |
| 7 | Wait 1 minute without leaving the app | Timer decrements by approximately 1 minute | - | - |

## Notes
- After the test, re-enable Set Automatically in device Settings
- Document exact timer value before and after for the bug report
- If timer freezes or shows negative value, capture a screenshot
