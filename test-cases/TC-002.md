# TC-002: Lives timer behavior when device time is changed manually

| Field | Value |
|-------|-------|
| Test Case ID | TC-002 |
| Requirement | [BUG-002](../bug-reports/BUG-002.md) |
| Module | Lives System |
| Test Name | Verify lives timer continues correctly after manual device time change |
| Priority | Medium |
| Test Environment | iPhone 15 Pro, iOS 17.4, Homescapes v6.x (latest App Store build) |
| Tester | Kseniia Romanovskaia |
| Test Date | 2026-04-03 |
| Status | Tested Successfully |

## Preconditions
- Homescapes is installed and launched
- Player has fewer than 5 lives
- Lives timer is actively counting down
- Access to device Settings is available

## Test Steps

| Step | Action | Expected Result | Actual Result | Status |
|------|--------|----------------|---------------|--------|
| 1 | Open Homescapes and confirm lives are below maximum | Lives counter shows less than 5, timer is visible | Lives: 4, timer visible and counting down | Pass |
| 2 | Note the current timer value | Timer value is recorded | Timer recorded: 29:42 | Pass |
| 3 | Minimize Homescapes and open device Settings | Device Settings opens | Settings opened | Pass |
| 4 | Navigate to General > Date and Time, disable Set Automatically, advance time by 1 hour | System time is manually changed | Time changed successfully | Pass |
| 5 | Return to Homescapes | App resumes | App resumed correctly | Pass |
| 6 | Observe the lives count and timer | Timer should reflect elapsed time correctly | Timer showed 27:22, continued counting down normally | Pass |
| 7 | Wait 1 minute without leaving the app | Timer decrements by approximately 1 minute | Timer decremented correctly | Pass |

## Result
Bug could not be reproduced on iPhone 15 Pro, iOS 17.4, Homescapes v6.x.
Timer value before time change: 29:42. Timer value after advancing device time by 1 hour: 27:22.
Timer continued counting down correctly after returning to the app.
The issue described in BUG-002 may have been fixed in a recent game update.

## Notes
- Device time was restored to automatic after the test
- Official Playrix Help Center still lists this as a known issue as of 2026-04-03
- Recommend re-testing on Android and on older iOS versions
