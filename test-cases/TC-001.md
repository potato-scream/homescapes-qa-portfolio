# TC-001: Level state preservation after incoming phone call

| Field | Value |
|-------|-------|
| Test Case ID | TC-001 |
| Requirement | [BUG-001](../bug-reports/BUG-001.md) |
| Module | Game Interruption |
| Test Name | Verify level progress is preserved when a phone call interrupts gameplay |
| Priority | High |
| Test Environment | iPhone 15 Pro, iOS 17.4, Homescapes v6.x (latest App Store build) |
| Tester | Kseniia Romanovskaia |
| Test Date | - |
| Status | Not Tested |

## Preconditions
- Homescapes is installed and launched
- Player has at least one active level available
- A second device or person is available to trigger an incoming call
- Lives are available (at least 1)

## Test Steps

| Step | Action | Expected Result | Actual Result | Status |
|------|--------|----------------|---------------|--------|
| 1 | Launch Homescapes and open any match-3 level | Level loads, move counter shows full count | - | - |
| 2 | Make 3-5 moves on the board | Tiles swap and match, move counter decrements | - | - |
| 3 | Note the current board state and remaining moves | Board layout and move count are visible and recorded | - | - |
| 4 | Trigger an incoming call on the test device | Call screen appears, game moves to background | - | - |
| 5 | Answer or decline the call, then end it | Call ends normally | - | - |
| 6 | Return to Homescapes | App resumes from background | - | - |
| 7 | Compare current board state with state noted in Step 3 | Board layout and move count match the state from Step 3, no lives deducted | - | - |

## Notes
- Repeat 3 times to verify consistency
- Test on both iOS and Android if possible
- If level resets, note whether a life was deducted
