# TC-003: Audio resumption after game interruption

| Field | Value |
|-------|-------|
| Test Case ID | TC-003 |
| Requirement | [BUG-003](../bug-reports/BUG-003.md) |
| Module | Audio |
| Test Name | Verify background music and sound effects resume after returning from interruption |
| Priority | Medium |
| Test Environment | iPhone 15 Pro, iOS 17.4, Homescapes v6.x (latest App Store build) |
| Tester | Kseniia Romanovskaia |
| Test Date | 2026-04-03 |
| Status | Tested Successfully |

## Preconditions
- Homescapes is installed and launched
- Music and sound effects are enabled in in-game settings
- Device volume is not muted

## Test Steps

| Step | Action | Expected Result | Actual Result | Status |
|------|--------|----------------|---------------|--------|
| 1 | Open Homescapes and confirm background music is playing | Music is audible | Music playing correctly | Pass |
| 2 | Press Home button to send app to background | App minimizes | App minimized | Pass |
| 3 | Wait 10 seconds | - | Waited 10 seconds | Pass |
| 4 | Return to Homescapes | App resumes | App resumed correctly | Pass |
| 5 | Observe whether background music resumed | Music resumes automatically | Music resumed immediately | Pass |
| 6 | Tap a UI element to trigger a sound effect | Sound effect plays | Sound effect played correctly | Pass |

## Result
Bug could not be reproduced on iPhone 15 Pro, iOS 17.4, Homescapes v6.x.
Audio resumed correctly after returning from background in all test runs.
The issue described in BUG-003 may have been fixed in a recent game update.

## Notes
- Tested 3 times, consistent result
- iPhone does not record system audio in screen recordings by default,
  so video evidence could not be captured for this test case
- Official Playrix Help Center still lists this as a known issue as of 2026-04-03
- Recommend re-testing on Android and on older iOS versions
