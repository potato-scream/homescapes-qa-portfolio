# TC-003: Audio resumption after game interruption

| Field | Value |
|-------|-------|
| Test Case ID | TC-003 |
| Requirement | [BUG-003](../bug-reports/BUG-003.md) |
| Module | Audio |
| Test Name | Verify background music and sound effects resume after returning from interruption |
| Priority | Medium |
| Test Environment | iPhone 15 Pro, iOS 17.4, Homescapes v6.x (latest App Store build) |
| Tester | Kseniia Romanovskaia |
| Test Date | - |
| Status | Not Tested |

## Preconditions
- Homescapes is installed and launched
- Music and sound effects are enabled in in-game settings
- Device volume is not muted
- Game is on the main menu or inside an active level

## Test Steps

| Step | Action | Expected Result | Actual Result | Status |
|------|--------|----------------|---------------|--------|
| 1 | Open Homescapes and confirm background music is playing | Music is audible | - | - |
| 2 | Confirm sound effects work by tapping a UI element | Sound effect plays | - | - |
| 3 | Press the Home button to send the app to background | App minimizes, music stops (expected on iOS) | - | - |
| 4 | Wait 10 seconds, then return to Homescapes | App resumes from background | - | - |
| 5 | Observe whether background music resumes automatically | Background music resumes within 2-3 seconds | - | - |
| 6 | Tap a UI element to trigger a sound effect | Sound effect plays correctly | - | - |
| 7 | Repeat steps 3-6 using an incoming call as the interruption trigger | Same result - audio resumes after returning from call | - | - |

## Notes
- If audio does not resume, try toggling sound settings off and on as a workaround
- Document whether the audio settings UI still shows sound as enabled while audio is silent
- Test both music and SFX separately
